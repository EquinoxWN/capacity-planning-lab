# Quality check, 2026-11-01

The ten engineering rules, checked against the code on `main`, with the evidence. Run on Windows 11
with Go 1.26.10 and Node.js 24.

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Assume every call can fail | fixed | **k6 child process:** it had no deadline, so a hung k6 blocked the runner until Ctrl-C. `K6.Load` now runs it under `DefaultK6Timeout` (12 min: the 600 s plan cap in `profiles.js`, 30 s graceful stop and start-up), fails with `k6 <kind> did not finish within ...`, and gives `k6 version` 30 s (`go/internal/runner/k6.go`, test `TestK6RunIsKilledAtItsTimeout`, which uses the test binary as a k6 that never finishes). **Ignored errors:** the error from removing a stale summary was dropped (`_ = os.Remove`), so an old `<kind>.k6.json` that could not be removed could be read as the new run's result. It now fails the run (`TestRunFailsWhenAStaleSummaryCannotBeRemoved`). The server `Shutdown` error is logged instead of dropped. The first CPU reading of the sampler was ignored (`s.prevCPU, _ = ProcessCPU()`): if it failed, the next sample's CPU share covered the whole process lifetime. It now needs two good readings in a row (`TestCPUUtilNeedsTwoReadingsInARow`). Other calls already had timeouts: health check `http.Client{Timeout: 1s}`, server read/write/idle timeouts, k6 requests `timeout: LIMITS.requestTimeout`. The remaining `_ =` are `strings.Cut` results and response writes after the status is sent. |
| 2 | Writes safe to retry | fixed | Run reports (`<kind>.json`, `<kind>.md`, `suite.md`) were written in place with `os.WriteFile`, so a crash mid-write left a truncated report that `rejudge` would then fail on. They now go through `writeFileAtomic`, a temporary file in the same folder that is renamed into place (`go/internal/runner/file.go`, `TestReportsAreReplacedWholeWithNoTemporaryFilesLeft`). Re-running a test overwrites its files, and `rejudge` is idempotent (`TestRejudgeRewritesStoredReports`). |
| 3 | No race conditions | pass | Shared state is behind `sync.Mutex` (`service/stats.go`, `usage/sampler.go`) or `atomic.Uint64`. The race detector needs cgo, which this machine lacks, so `go test -race` runs in CI (`make test`). `TestConcurrentLoadAccountsForEveryRequest` sends 200 concurrent requests. |
| 4 | Don't trust the clock | pass | Durations are `time.Since`/`Sub` on `time.Now()` values, which use Go's monotonic clock. The stored `startedAt` is `started.UTC().Format(time.RFC3339)`. Samples are ordered by sampler offset, not by wall-clock timestamps. |
| 5 | Read before changing | pass | Environment read by the k6 scripts (`BASE_URL`, `SUMMARY_PATH`, `SCALE`, `RATE`, `PEAK`, `HOLD_S`, `STEPS`) is documented in the README and validated in `profiles.js`. The Go code reads no environment variables; the new `CAPLAB_FAKE_K6` is test-only (`quality_test.go`). Every path in the README path table exists. |
| 6 | Never break compatibility | pass | The report JSON and the k6 summary contract (`testdata/contract/summary-v1.json`) are unchanged. `K6.Timeout` is a new optional field, and its zero value keeps the default. |
| 7 | One source of truth | pass | The SLO and limits live in `profiles.js`. The Go side reads the SLO from the summary and does not copy it. `allowedDrops` mirrors the JS budget, and both are now pinned by tests with a fractional budget. The k6 version and SHA-256 are pinned only in `scripts/get-k6.sh`. Go 1.26.10 is the same in `go.mod`, CI and the README. |
| 8 | Small changes, no secrets, validate input | pass | `grep -riE "(api[_-]?key|secret|token|password)\s*[:=]"` matches only the fake `K6_CLOUD_TOKEN=secret` in a test that proves it is not inherited. CLI flags, the loopback address, plan length, steps, rates and summary files are validated (`TestRunRefusesBadInput`, 13 broken summaries, the `environment input is validated` test). No new dependency. |
| 9 | Tests that can actually fail | fixed | No skipped or tautological tests (`t.Skip` is used only where the platform has no CPU counter, with the reason in the message). Mutation check below: 8 of 14 mutants survived, and each now has a test that kills it. |
| 10 | Re-verify | pass | gofmt clean, `go vet ./...` clean, `go test -count=1 ./...` 43 passed (5 packages ok), `npm run lint` (tsc strict) clean, `node --test` 17 passed, govulncheck: no vulnerabilities, `npm audit`: 0, `audit_repo.py`: OK. CI runs `-race` and the quick suite. |

- `go/internal/usage/cpu_baseline_test.go` (1): CPU share only from two good readings in a row.
